## 🚀 Featured Projects

### 🎲 [BoardGame Database — End-to-End CI/CD Pipeline](https://github.com/kfchacha/Board-Game)

> Full production DevOps pipeline: GitHub → Jenkins → Maven → SonarQube → Trivy → Nexus → Docker → Kubernetes on AWS EC2

**What I built:**
- 14-stage declarative Jenkins pipeline completing in **~75 seconds**
- Dual Trivy security scanning (filesystem + Docker image) with report emailed on every build
- SonarQube static analysis with quality gate enforcement
- Artifact published to Sonatype Nexus, Docker image pushed to Docker Hub
- Kubernetes deployment on a 3-node AWS EC2 cluster (eu-north-1) with KubeAudit post-deployment scan
- Automated Gmail notifications with scan report attached

**Stack:** `Jenkins` `Maven` `SonarQube` `Trivy` `Nexus` `Docker` `Kubernetes` `AWS EC2` `KubeAudit`
